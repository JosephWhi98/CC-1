# Changelog

## 0.10.0 (pre-release)
- New BASIC style: flat, hairline borders, one accent. Colourways BASIC (white) and BASIC DARK
- Update check against GitHub releases, with a dot on SETTINGS and a download button (switch off in Settings)

## 0.9.0 (pre-release)
- Auto-named sessions (toggle in Settings)
- Custom colours per theme, savable as named themes
- Reactive avatar display, six new scenes, CYCLE mode
- Optional remote access over the LAN: QR pairing, per-device tokens, restricted device permissions
- App versioning (VERSION file, shown in Settings, Mac bundle and Windows build)
- Native Windows build (C# + WebView2, no Electron): windows-native/
