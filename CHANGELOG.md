# Changelog

## 0.11.4 (pre-release)
- New JARVIS style: holographic HUD with corner brackets, hairline glow and an arc-reactor logo. Colourways JARVIS (cyan) and MARK III (red and gold)

## 0.11.3 (pre-release)
- Toggle switches: fixed the round thumb spilling out of the square tracks in BRUTAL, BLUEPRINT, PHOSPHOR and RUNNER

## 0.11.2 (pre-release)
- Mini-games on the display (FLAP, BREAK, SNAKE, HOP): press PLAY under the display. Claude's status stays visible while you play
- RETRO theme: toggles are now slide switches with a lamp
- Version number beside the logo; it glows and links to Settings when an update is available

## 0.11.1 (pre-release)
- New BLISS display scene: line-art rolling hills and drifting clouds (also in CYCLE)
- BASIC theme: the avatar screen stays dark so scenes show up

## 0.11.0 (pre-release)
- UPDATE NOW: one-click in-app update on Mac and Windows. Downloads the release, checks its SHA-256, swaps the app and relaunches (with rollback). MANUAL download is still there

## 0.10.0 (pre-release)
- New BASIC style: flat, hairline borders, one accent. Colourways BASIC (white) and BASIC DARK
- Update check against GitHub releases, with a dot on SETTINGS and a download button (switch off in Settings)

## 0.9.0 (pre-release)
- Auto-named sessions (toggle in Settings)
- Custom colours per theme, savable as named themes
- Reactive avatar display, six new scenes, CYCLE mode
- Optional remote access over the LAN: QR pairing, per-device tokens, restricted device permissions
- App versioning (VERSION file, shown in Settings, Mac bundle and Windows build)
- Native Windows build (C# + WebView2, no Electron): windows-native/

## 0.1.0
- Initial prototype
